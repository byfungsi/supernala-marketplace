# Phase 1 compatibility

The Marketplace contract is pinned to committed and locally merged Plugin integration `9e020887a5619d81bcda135cd729af360c6a3096`, fast-forwarded from parent main `ad5c0ddd7feae44ce21c8aaf7ad7c8afdbf6f645`. This compatibility reference does not claim deployment; `compatibility/phase-1-sources.json` pins the exact reviewed files.

The portable implementation preserves the two runtime descriptors, branded identity constraints, canonical JSON digesting, ZIP safety limits, package manifest/catalog/config semantics, private R2 object-key formula, and internal publication input shape. No absolute import or file dependency points at the application repository.

The application currently exposes `publishPackagedPluginVersion` and `reconcilePackagedPluginPublication` only as internal functions requiring `{ database: D1Database; packages: PluginPackageBucket }`. The locally merged integration adds strict `github-app` package metadata, digest-bound full MIT evidence, reviewed authentication expectations, exact provider fencing, and verified Config schema reuse by digest without changing the control-plane SQL bytes; integration allocates that migration as `0042_plugin_control_plane.sql`. There is no authenticated production publication endpoint. The Marketplace release adapter instead targets documented Cloudflare D1/R2 interfaces and remains disabled until its credentials and environments are explicitly approved; Cloudflare D1 tokens are not assumed to enforce table-level authority. `plan-publication` remains a checked offline contract artifact.

Pinned Phase 1 resolves Config schemas by exact digest, revision, and recursively strict canonical fields, reuses the actual persisted identity (including legacy IDs), and assigns new rows `config:sha256:<digest>`. Concurrent alternate-ID winners are accepted only after rollback and exact bounded re-resolution. Migration `0042_plugin_control_plane.sql` retains the accepted SQL digest, and Phase 1 is not modified here.
