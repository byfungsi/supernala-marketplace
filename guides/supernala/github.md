# Set up GitHub

GitHub lets your Bots read repositories, issues and pull requests you can access, and make changes such as comments after you approve. Supernala signs in through its own GitHub App, so you do not create any keys.

## In Supernala

1. Open **Marketplace → Apps → GitHub** and click **Install**.
2. Click **Connect GitHub account** and authorize Supernala on GitHub.
3. Choose which Bots can use GitHub and click **Save changes**. Changes still ask for your approval.

## If something goes wrong

- **An organization's repositories are missing**: the organization may restrict third-party access. Ask an organization owner to approve the app, or request access from GitHub's authorization page.
- **Asked to reconnect**: you revoked the authorization in GitHub settings, or GitHub ended it. Connect again.
