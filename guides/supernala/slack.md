# Set up Slack

Slack lets your Bots read channels, messages and files you can access, and post, react or update canvases and lists after you approve. Supernala already has a Slack app, so you only sign in.

## Before you start

- A Slack account in the workspace you want to connect.
- If your workspace only allows approved apps, an admin may need to approve Supernala first.

## In Supernala

1. Open **Marketplace → Apps → Slack** and click **Install**.
2. Click **Connect account**, choose your Slack workspace and allow access.
3. Choose which Bots can use Slack and click **Save changes**. Posting and other changes still ask for your approval.

## If something goes wrong

- **Your workspace requires approval**: ask a Slack admin to approve the app, then connect again.
- **A channel is missing**: Bots see only what your Slack account can see, including private channels you are in.
- **Asked to reconnect**: Slack ended the sign-in, for example after you changed your password or an admin removed the app. Connect again.
